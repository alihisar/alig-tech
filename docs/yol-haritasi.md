Working rule: **two items per day** are done (a night task; first tests, then code, then all checks), and each item is marked
in this file when it is finished. The order is in the "Daily plan" table below; a blocked item is skipped and the next unblocked item is taken.
For topics that await approval but do not block the work, work proceeds with a default value; the default is
written to the "Proceeding with a default" table so it can be changed with a single line. Blocking decisions (`docs/kararlar.md`) are not coded.
