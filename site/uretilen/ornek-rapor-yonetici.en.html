Actions in priority order

  1. Connection count is close to the limit. Use a connection pooler and reduce application pool sizes. Raise max_connections only as a last resort (memory cost). (effort: medium)
  2. Tables with a high dead-row ratio. Review per-table autovacuum settings (scale_factor, cost) and check for long transactions blocking cleanup. (effort: medium)
  3. Password hashes are stored as MD5. Set password_encryption to scram-sha-256, renew role passwords in turn and switch pg_hba.conf rules to scram. (effort: medium)
  4. Large indexes that were never used. Check when statistics were last reset and usage on all replicas; consider dropping once sure. (effort: small)
